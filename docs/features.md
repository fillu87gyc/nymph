# thyrs 機能一覧

実装済みのすべての機能を記録する。

---

## コア表示

| 機能 | 概要 |
|------|------|
| Markdown ホットリロード（SSE） | ファイル変更を Server-Sent Events でリアルタイム反映 |
| Mermaid ダイアグラムレンダリング | コードブロックをフローチャート等に描画 |
| draw.io エクスポート | Mermaid 図を draw.io 形式でダウンロード |

## コメント機能

| 機能 | 概要 |
|------|------|
| ブロック単位インラインコメント | 行番号紐づけ・JSON 保存 |
| テキスト選択コメント | 選択範囲を context として記録 |
| コメント編集 | 既存コメントの修正 |
| スクロール同期 | プレビューとコメントパネルの同期スクロール |
| レビューのクリップボードコピー | コメント一覧をクリップボードへ一括コピー |

## ファイル管理

| 機能 | 概要 |
|------|------|
| 複数ファイルウォッチ | glob・ディレクトリ対応、タブ切替 UI |
| ドラッグ & ドロップ | ファイルをブラウザにドロップして監視切替 |

## 差分・履歴

| 機能 | 概要 |
|------|------|
| チェックポイント | 任意タイミングのスナップショット保存 |
| ± diff ハイライト | チェックポイントとの差分を色分け表示 |

## UI / UX

| 機能 | 概要 |
|------|------|
| ダーク / ライトテーマ切替 | ワンクリックでテーマ変更 |

## Claude Code 連携

| 機能 | 概要 |
|------|------|
| Edit ツール hook 連携 | Edit ツール使用時にコメント行番号を自動リマップ |
