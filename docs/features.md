# nymph 機能一覧

実装済みのすべての機能を記録する。

---

## コア表示

| 機能 | 概要 |
|------|------|
| Markdown ホットリロード（SSE） | ファイル変更を Server-Sent Events でリアルタイム反映 |
| Mermaid ダイアグラムレンダリング | コードブロックをフローチャート等に描画 |
| draw.io エクスポート | Mermaid 図を draw.io 形式でダウンロード |

## コメント機能

| 機能 | 概要 |
|------|------|
| ブロック単位インラインコメント | 行番号紐づけ・JSON 保存 |
| テキスト選択コメント | 選択範囲を context として記録 |
| コメント編集 | 既存コメントの修正 |
| スクロール同期 | プレビューとコメントパネルの同期スクロール |
| レビューのクリップボードコピー | コメント一覧をクリップボードへ一括コピー |
| コメントのステータス | 未解決 / 削除済 / 解決済 の自動判定とフィルタ |
| もとの文章スナップショット | 作成時点の対象行 + 前後 5 行を保存し吹き出しで表示 |

## ファイル管理

| 機能 | 概要 |
|------|------|
| 複数ファイルウォッチ | glob・ディレクトリ対応、タブ切替 UI |
| ドラッグ & ドロップ | ファイルをブラウザにドロップして監視切替 |
| Quick Open（Ctrl/Cmd+P） | ファイル名のあいまい検索パレット |
| キーボードショートカット | `?` で一覧、`C` でコメントパネル開閉、`T` でテーマ切替。入力中・IME 変換中・モーダル表示中は拾わず、`Ctrl` / `Cmd` との同時押しでも反応しない（ブラウザ / OS の操作を奪わない）。一覧は「⋯」メニューの **⌨ ショートカット一覧** からも開ける |
| 全文検索 | Quick Open に統合。ファイル名+本文を検索し、前後コンテキスト付きスニペットから該当行へジャンプ（`GET /search`） |
| 起動中インスタンスへの追加 | 既に nymph が動いている状態で別ターミナルから `nymph <file>` を実行すると、新しいプロセスを立てず既存インスタンスのタブとして開く。開きっぱなしの画面はリロードやフォーカス操作なしにタブが増えて切り替わる（`/watch` の `filesChanged` push） |

## 差分・履歴

| 機能 | 概要 |
|------|------|
| チェックポイント | 任意タイミングのスナップショット保存 |
| ± diff ハイライト | チェックポイントとの差分を色分け表示 |

## UI / UX

| 機能 | 概要 |
|------|------|
| ダーク / ライトテーマ切替 | ワンクリックでテーマ変更（ダーク: Tokyo Night 系 / ライト: GitHub Primer 系） |
| ツールバー構成 | 常時表示9個 + 「⋯」オーバーフローメニュー + 「⚙」設定ポップオーバーの3群構成 |
| 本文幅のドラッグ調整 | 本文の左右端をドラッグして幅を任意に変更（左右キー / ダブルクリックでリセット、localStorage に保存） |
| 本文幅プリセット | 設定ポップオーバーの左右マージン折りたたみで 960 / 1280 / 1600px を切替 |
| リガチャ切替 | 設定ポップオーバーで合字の有効 / 無効を切替（既定は有効）。本文の fi / fl やコード・差分の `=>` `!=` を 1 文字ずつ表示できる。localStorage に保存 |
| アウトラインパネル（旧・目次） | 見出しジャンプに加え、見出し配下の未解決コメント数・チェックポイントからの diff 増減をバッジ表示。差分チェックモード中も開閉可能。バッジ種別（非表示 / コメント数 / 差分量 / 両方）は設定ポップオーバーで切替・永続化 |
| ウィジェット配置 | 画面左右の枠に、タブ / エクスプローラー / アウトライン / コメントを自由に積める。1 つの枠に複数を縦に並べられる（例: 左＝タブ + アウトライン）。localStorage に永続化。タブは既定の横行、コメントは既定の下ドックにも戻せる |
| 検索結果ウィジェット | 枠に常設できる全文検索パネル。Quick Open と同じ `GET /search` を叩き、結果を見ながら次々にファイル+行へ飛べる |
| 最近 / ブックマークウィジェット | ツールバーのメニューにしかなかった履歴とブックマークを枠に常設。ファイルは開き、ディレクトリはツリーのルートに切り替える |
| ミニマップウィジェット | 文書全体を 1 行 = 1 本の棒に潰した俯瞰図。種別（見出し / コード / 表…）で色分けし、コメント位置を点で重ねる。今見ている範囲を枠で追従表示し、クリックでその行へジャンプ |
| 図の一覧ウィジェット | 本文中の Mermaid（```mermaid / ```mmd）を種類（graph / sequenceDiagram …）と先頭行つきで一覧し、図へジャンプ |
| タスクウィジェット | `- [ ]` / `- [x]` を集めて完了数つきで一覧。「未完のみ」で絞り込み、選ぶとその行へジャンプ |
| リンク / 画像ウィジェット | リンクと画像を一覧。相対パスはサーバー（`POST /link-check`）に実在を問い合わせて ✓ / ✗ を出す（判定範囲はルート配下、無ければ開いているファイルのディレクトリ配下。外に出るものは「?」） |
| 用語集ウィジェット | 辞書（`.nymph/dict.json`）の用語を一覧・絞り込み。本文中の出現回数を添え、選ぶと最初の出現行へジャンプ |
| frontmatter ウィジェット | 本文先頭の YAML メタ情報をキー / 値の表で常時表示 |
| 差分サマリウィジェット | チェックポイントからの ±行数と変更のかたまりを一覧。選ぶと差分チェックモードへ入りその行をハイライト |
| 文書統計ウィジェット | 文字数・行数・単語数・見出し / コード / 表 / リンク / タスクの数と推定読了時間 |
| ウィジェット配置画面 | ⚙ 設定 →「配置を編集」で開く専用画面。「利用可能」一覧と左右の枠のあいだをドラッグ＆ドロップで移し、枠の中の上下の順番もドラッグで入れ替える。矢印キー（← → で枠、↑ ↓ で並び順）でも操作できる。変更は即座に反映・保存され（apply/cancel は無い）、「初期配置にリセット」で初期状態に戻せる。既定位置を持たないウィジェット（検索結果・ミニマップなど）は枠に置いたときだけ画面に出る。枠のチップには中身の縮小プレビュー（実際に並ぶ先頭 3 件と総数）が付き、条件を満たさず今は出ていないもの（ルート未指定のエクスプローラーなど）には理由と出し方を添える |
| 縦タブ（Open Editors） | タブを左右の枠に置くと VSCode の Open Editors のような縦リストになる。横行は 2 ファイル以上でのみ出るが、縦置きは 1 ファイルでも表示する |
| ウィジェット枠の幅調整 | 枠と本文の境目をドラッグして左右の枠の幅を個別に変更（140〜480px、左右キー / ダブルクリックで既定幅にリセット、localStorage に保存）。本文の行長を変える「本文幅のドラッグ調整」とは掴む場所も変わるものも別 |

## エクスポート・出力

| 機能 | 概要 |
|------|------|
| HTML エクスポート | `nymph <file> --export <out.html>` で、本文と保存済みコメントを 1 枚の静的 HTML に書き出す（サーバーは起動せず終了）。CSS / JS / 画像（ファイルと同じディレクトリ配下の相対パスのみ、1枚 2MB まで）をすべてデータ URI・インラインで焼き込み、外部ホストを一切参照しない。コメントは対象ブロックの直後に状態・行番号・ラウンド・「もとの文章」つきで並び、対象が消えたものと差分への指摘は末尾にまとめる。ヘッダーで解決済みの折りたたみとテーマ切替（初期値は OS 設定に追従）。生 HTML はエスケープして literal 表示、印刷用 CSS 付き |
| 印刷 / PDF | 「⋯」メニューの **印刷 / PDF** でブラウザの印刷ダイアログを開き、そのまま PDF に保存できる。紙にはツールバー・枠・パネル・操作ボタンは出ず本文だけが載り、テーマがダークでも配色はライトに倒す（ブラウザは既定で背景色を印刷しないため）。コード・表・図はページの切れ目をまたがず、長いコード行は折り返す。コメントは紙に出ないので、コメント入りが要るときは HTML エクスポート（⋯ → エクスポート、または `--export`）を印刷する |
| Markdown 書き戻し | `nymph <file> --annotate <out.md>` で、保存済みコメントを本文の各ブロック直後へ `> [nymph] 状態 · 行番号 · ラウンド · 日時` の引用として挿し込んだ Markdown を書き出す（サーバーは起動せず終了）。本文の行は書き換えず、足すのは引用と区切りの空行だけ。対象が消えた指摘と差分への指摘は末尾の「本文に紐づかないコメント」へまとめ、末尾に出力日時と件数の HTML コメントを残す。`--annotate-open` で解決済みを除ける。元ファイルへの上書きは拒否する |
| CSV エクスポート | `nymph export <file> [-o <out.csv>] [--bom]` で保存済みコメントを 1 件 1 行の CSV（RFC 4180 / CRLF / UTF-8）にする。列は `file, id, status, line_start, line_end, block_type, round, created_at, target, comment` で、`status` は他の出力と同じ規則（open / deleted / resolved）。`-o` を省くと標準出力へ流す（そのままパイプできる）。`--bom` は Excel 向け。`=` `+` `@` で始まる値は数式として評価されないよう無害化する |
| 画面からのエクスポート | 「⋯」メニューの **エクスポート** から、CLI と同じ 3 形式（📄 HTML = `--export` / 📝 Markdown = `--annotate` / 📊 CSV = `nymph export`）をブラウザに直接ダウンロードする。中身は CLI と同一（組み立てを共有）。ファイル名は `<元の名前>-review.<拡張子>`、生成物はサーバーのディスクに残さない。**Mermaid を同梱** のチェックで `--export-mermaid` 相当（既定 off）。CSV だけは既定を反転して BOM 付き（行き先がほぼ表計算ソフトのため）。対象は開いているファイルのみで、ドロップ由来の擬似タブでは無効 |
| Mermaid 描画エンジンの同梱 | `--export-mermaid`（画面からは「Mermaid を同梱」）でエクスポートに mermaid 本体（`dist/mermaid-standalone.js`）を焼き込み、オフラインのまま図を描画する。図が無い文書には積まない。描画に失敗した図はソース表示のまま残し、テーマ切替で描き直す。CDN 取得は採らない（配布物からの第三者接続と、動的 import のため SRI が効かないことが理由） |

## 用語辞書（dict）

| 機能 | 概要 |
|------|------|
| `nymph dict build` | `.nymph/config.yml` の各ソースをコマンド実行で取得し、セレクタで用語 / 定義 / エイリアスを抜いて `.nymph/dict.json` を生成。Markdown / JSON アダプタ対応、TTL キャッシュ、`--debug` で中間木とマッチ結果を出力。書式は `src/dict/README.md` |
| `nymph dict allow` | `config.yml` に書かれた `fetch.cmd` を一覧表示して承認を取る（direnv allow 相当）。コマンドのハッシュを保存し、未承認のまま `dict build` は走らない |
